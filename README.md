# molterm in the browser

**Live: https://shinwachi.github.io/molterm-web/**

Chemical structures drawn as text and terminal pictures, entirely in the browser: RDKit compiled to WebAssembly (RDKit.js) lays out
and draws the molecule, molterm's text renderer, ported to JavaScript, turns the drawing into coloured Braille or ASCII, and
[restty](https://github.com/wiedymi/restty) shows the result as a terminal would, with Kitty graphics for the picture mode. There is no
server: these are plain static files.

This repository holds only the built site. It is generated by `make -C web export` in the molterm project; edit the source there,
not here.
